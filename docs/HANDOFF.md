Поддерживать единый статический сайт без локальных копий общих UI-компонентов.

- Репозиторий: https://github.com/darya499/darya499.github.io
- GitHub Pages: ветка `main`, папка `/(root)`.

## Порядок работы

1. Открыть `docs/COMPONENTS.md` и проверить, есть ли нужный элемент в `components/`.
2. Для главной править авторитетные входы и запускать `assemble.py`.
3. Для кейса 169 править `build_case_169.py` или `pages_raw/projects-169-body-ru.html`, затем запускать `build_case_169.py` и `assemble_case_169.py`.
4. Запустить `build_github_package.ps1` в исходной `scratchpad` — он полностью пересоздаёт только `github-pages-site/`.
5. Статически проверить: есть `index.html`, `case-169/index.html`, `404.html`, `components/README.md`, все локальные пути существуют, карточка 169 ссылается на `case-169/`.
6. Отдельно проверить визуально desktop и mobile до публикации. Эта проверка не заменяется анализом HTML.

## Границы

- Не создавать кейс `106` и не переименовывать `169`, пока владелица не передаст реальный источник/целевой URL.
- Не публиковать английские шаблонные дубли без отдельного решения.
- Не редактировать библиотеки через копии на страницах.
- Не удалять исходники или резервные файлы без отдельного подтверждения.
