# Карта компонентов сайта

`components/` содержит CSS и JavaScript повторяемых элементов. В опубликованных страницах есть также встроенная разметка и стили, поэтому изменение файла библиотеки действует только там, где страница на него ссылается.

| Компонент | Исходники | Обязательная проверка |
| --- | --- | --- |
| Шапка | `header/header.css`, `header/header.js` | desktop от 768px и mobile ниже 768px; меню, hover, active, focus |
| Кнопки | `button/button.css`, `button/button.js` | normal, hover, focus; текст и иконка |
| Подвал внутренних страниц | `footer/footer.css`, `footer/footer.js` | desktop и mobile; ссылки и иконки |
| Типографика | `Inter` 100–900 через Google Fonts | сверить веса и контраст на каждой странице |

## Где изменения действуют

Главная подключает внешние файлы шапки и кнопок; её подвал устроен отдельно. `/case-169/`, `/cases/`, `/feed/` и `/blog/` подключают внешние файлы шапки, кнопок и подвала. `/cases/axiom/` не подключает эти файлы, хотя сейчас показывает копию кейса 169.ru. Другие маршруты проверяйте по их тегам `<link>` и `<script>` перед общей правкой.

Перед изменением общего компонента откройте страницы, где он подключён, и проверьте desktop и mobile. Если меняется только один кейс, редактируйте его файл и не переносите правку автоматически на другие маршруты. `ui-kit.html` в этом репозитории отсутствует; для проверки используйте реальные опубликованные страницы.
