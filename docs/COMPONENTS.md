# Библиотека компонентов: источник правды

`components/` — единственная библиотека повторяемого UI сайта.

| Компонент | Исходники | Обязательная проверка |
| --- | --- | --- |
| Шапка | `header/header.css`, `header/header.js` | desktop от 768px и mobile ниже 768px; закрытое и открытое меню, hover, active, focus, scroll-state |
| Кнопки | `button/button.css`, `button/button.js` | normal, hover, focus, disabled; текст и иконка меняют цвет синхронно |
| Подвал внутренних страниц | `footer/footer.css`, `footer/footer.js` | desktop и mobile; текст, email, соцсети, иконка Setka |
| Типографика | `Inter` 100–900 через Google Fonts | сверить веса и контраст на каждой странице |

## Непреложное правило

1. Сначала найти элемент в `components/`.
2. Если он есть — менять только его исходник и проверять состояния в `ui-kit.html` исходной папки.
3. Если его нет — добавить компонент в библиотеку, его живой пример в `ui-kit.html`, затем использовать на странице.
4. Нельзя добавлять локальные дубли CSS/JS шапки, кнопок или подвала на отдельную страницу.

Главная подключает из библиотеки шапку и кнопки. Внутренние страницы подключают также футер. Изменение компонента действует на маршрутах, где подключён его CSS/JS; после изменения проверьте эти страницы на desktop и mobile.
