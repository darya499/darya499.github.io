# Работа с GitHub: безопасный порядок

## Что можно делать прямо в GitHub

После загрузки пакета в репозиторий можно выполнить срочную правку текста через **Edit**. Она попадёт в историю GitHub, но следующая локальная сборка перезапишет её. Чтобы изменение сохранилось, внесите его и в авторитетный исходник, указанный в `docs/ROUTES.md`. Изображения и PDF заменяйте вместе с проверкой ссылок на них.

## Общие UI-компоненты

Шапка, кнопки и подвал не редактируются в страницах. Для них открывают только:

- `components/header/header.css` и `components/header/header.js`;
- `components/button/button.css` и `components/button/button.js`;
- `components/footer/footer.css` и `components/footer/footer.js`.

Главная подключает общие файлы шапки и кнопок. Кейс 169 и русские дополнительные страницы также подключают общий футер. После правки компонента GitHub Pages обновит только те маршруты, где этот файл подключён.

## Как добавить новый кейс

1. Не копировать `case-169/index.html` прямо в GitHub: он собран из источников.
2. В исходной рабочей папке создать подтверждённый исходник и маршрут, обновить ссылку на главной, затем запустить `build_github_package.ps1`.
3. Проверить новый `case-<номер>/index.html`, ссылку с главной и `docs/ROUTES.md`.
4. Загрузить изменённые файлы в GitHub отдельным commit, например `Add case 170`.

## Как обновить сайт из исходников

1. Главная: править `final-body3.html`, `final2.css`, `assemble.py`, затем запускать `assemble.py`.
2. Кейс 169: править `build_case_169.py` или `pages_raw/projects-169-body-ru.html`, затем запускать `build_case_169.py` и `assemble_case_169.py`.
3. Запустить `build_github_package.ps1`.
4. Загрузить содержимое заново собранной `github-pages-site/` в GitHub.

Перед загрузкой нового пакета сравните его с текущей веткой `main`: на каждой HTML-странице должен быть `<meta name="viewport">`, а ссылки общей шапки и подвала должны вести на `/`, `/cases/` и `/feed/` относительно корня сайта. Исправления от 17 сентября 2026 внесены в рабочую Git-копию; временные исходники Claude пока не обновлены. В кейсе 169.ru и его шаблонном дубликате `/cases/axiom/` также сохранён размер чисел в карточках результатов без переноса.

GitHub Pages не исполняет Python и PowerShell. Поэтому сложные структурные изменения и добавление кейсов выполняются из исходной папки, а GitHub хранит и публикует готовый статический результат.
