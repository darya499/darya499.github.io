# Портфолио Дарьи Максимовой — GitHub Pages

- **Сайт:** https://darya499.github.io/
- **Репозиторий:** https://github.com/darya499/darya499.github.io
- **Публикация:** GitHub Pages из ветки `main`, папка `/(root)`.

Это рабочая Git-копия готового статического пакета. Файлы сайта лежат в корне репозитория; `docs/` содержит карту маршрутов, компонентов и порядок обновления.

## Публичные маршруты

- `/` — главная;
- `/case-169/` — подтверждённый кейс 169.ru;
- `/cases/`, `/feed/`, `/blog/`, `/privacy-policy/`, `/terms/` — остальные существующие русские страницы;
- `/404.html` — страница ошибки GitHub Pages;
- `/daria-maksimova-resume.pdf` — PDF резюме, открываемый кнопкой скачивания на главной.

Часть дополнительных страниц (`/cases/`, `/blog/` и вложенные маршруты) сохраняет материалы исходного шаблона Joseph Alexander. Они включены в эту публикацию по решению владелицы сайта; единственный подтверждённый авторский кейс в пакете — `/case-169/`.

Карточка 169.ru на главной ведёт на относительный путь `case-169/`, поэтому работает и в GitHub Pages проекта, и на собственном домене. Кейс `106` в исходной папке отсутствует: маршрут для него намеренно не создан.

## Принцип поддержки

Перед любым UI-изменением откройте `components/README.md`. Карта файлов и маршрутов — в `docs/`. Для постоянных изменений правьте исходники в рабочей папке проекта и пересобирайте пакет; правка опубликованного HTML непосредственно в GitHub будет потеряна при следующей сборке.

GitHub Pages: [официальная инструкция по источнику публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
